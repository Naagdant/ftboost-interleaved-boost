# Fault-tolerant two-phase interleaved boost converter (48 V → 200 V)

KiCad design, SPICE models and Python co-simulation code for the paper

> K. D. Bodha, V. Arun, A. Awasthi, *Current-Only Diagnosis and Hybrid Isolation of Open-Inductor, Stuck-On-Switch
> and Open-Diode Faults in a Two-Phase Interleaved Boost Converter for 48 V Electric-Vehicle Buses* (submitted).

A two-phase, 50 kHz, 48 V → 200 V interleaved boost converter that detects, classifies and isolates an
**open inductor**, a **stuck-on (shorted) switch** or an **open diode** in either phase and keeps regulating
on the remaining phase. Diagnosis uses only the per-phase current sensors: each off-time window of the sensed
current is compared with a healthy template through the Pearson correlation and a load-independent slope
ratio. Each phase is isolated on its input side by a solid-state disconnect (SSD) in series with a relay.

The converter is drawn in KiCad, exported to SPICE and simulated with the ngspice shared library bundled
with KiCad. The controller runs as discrete-time Python "firmware" coupled to ngspice through its
external-source and data callbacks.

## Repository layout

| Path | Contents |
|---|---|
| `kicad/ft_boost/` | KiCad project used for simulation (`ft_boost.kicad_sch`, generated by `sim/gen_schematic.py`), its exported netlist `ft_boost.cir`, the SPICE models `ft_boost_models.lib` and a schematic plot |
| `kicad/ft_boost/netlists/` | Exact netlist of every simulated run of the main study (faults, C_out, overrides and load step applied), written by `sim/export_netlists.py` |
| `kicad/ft_boost_wired/` | Wired, publication-layout schematic (Fig. 2 and Fig. A.1), generated by `sim/gen_schematic_wired.py`; `sim/check_wired_netlist.py` checks that its netlist matches the simulated one |
| `sim/` | Firmware model, co-simulation drivers, analysis and figure scripts (table below) |
| `results/` | Per-run event logs and settings (`*.json`) and run summaries (`summary.json/.csv`, `random_fault_summary.*`, `detector_benchmark.json`, `threshold_sensitivity.json`, `replay_*.json`, `rev3_summary.json`) |

Raw waveforms (`results/*.npz`, about 630 MB) are not stored in this repository; see *Raw data* below.

## Requirements

* KiCad 10 (for `kicad-cli` and its bundled `libngspice`). The scripts look for KiCad at
  `/Applications/KiCad` (macOS); edit `KICAD_CLI` in `sim/netlist.py` and `LIB_CANDIDATES` in
  `sim/ngspice_shared.py` for other installations.
* Python 3.10+ with the packages in `requirements.txt`.

```bash
pip install -r requirements.txt
```

Run every command from the repository root.

## Reproducing the results

```bash
# 1. schematic and netlist
python -I sim/gen_schematic.py
python -I sim/gen_schematic_wired.py && python -I sim/check_wired_netlist.py

# 2. open-loop model check (Table 6, Fig. 5)
python -I sim/openloop_validation.py

# 3. main fault matrix, current design (Table 7, Figs. 6-9)
for c in healthy open_inductor shorted_switch open_diode; do
  python -I sim/run_case.py $c --blank 0 --relay-delay 5e-3 --tag final
  python -I sim/run_case.py $c --blank 0 --relay-delay 5e-3 --cout 150e-6 --tag c150u_final
done

# 4. conventional converter (Table 9, Fig. 11) and random fault instants (Table 8, Fig. 10)
python -I sim/run_case.py open_diode --baseline --tag baseline          # likewise for the other faults
python -I sim/run_case.py open_diode --tfault 0.05123 --seed 3 --tag rand00   # see results/*_rand??.json for the settings
python -I sim/random_summary.py

# 5. input fuse, avalanche energy, relay-only isolation (revision 2; Tables 9 and 15, Fig. 13)
python -I sim/run_extra.py shorted_switch --baseline --fuse --tag baseline_fuse
python -I sim/run_extra.py shorted_switch --fuse --tag final_fuse
python -I sim/run_extra.py open_diode --aval --tag final_aval
python -I sim/run_extra.py open_diode --baseline --aval --tag baseline_aval

# 6. saturation, transistor-level SSD, start-up and double faults (revision 3; Tables 16-17, Fig. 16)
python -I sim/run_rev3.py --tag rev3_sat72_open_diode --sat 7.2 --faults open_diode:1@0.05
python -I sim/run_rev3.py --tag rev3_ssdreal_shorted_switch --ssd-real --faults shorted_switch:1@0.05
python -I sim/run_rev3.py --tag rev3_su_early_open_diode --early-arm --faults open_diode:1@0.005
python -I sim/run_rev3.py --tag rev3_dbl_ol1_sc2 --faults open_inductor:1@0.05,shorted_switch:2@0.06
python -I sim/analyze_rev3.py

# 7. scoring, offline detector studies, exports
python -I sim/analyze.py
python -I sim/replay.py --tags final c150u_final --noise 1 2 3 5 8 --blank 0 --seeds 5
python -I sim/detector_benchmark.py
python -I sim/export_csv.py && python -I sim/export_netlists.py

# 8. figures
python -I sim/paper_figs_elsevier.py && python -I sim/fig_revision.py && python -I sim/fig_circuit.py
```

The exact settings of every stored run (fault instant, seed, C_out, relay delay, overrides) are recorded in
its `results/<run>.json`, and the exact netlist in `kicad/ft_boost/netlists/<run>.cir`.

## Run-name tags

| Tag | Meaning |
|---|---|
| `*_final`, `*_c150u_final` | Current design: SSD + 5 ms relay, sensor noise on, duty-adaptive window, no blanking; C_out = 14 µF / 150 µF |
| `*_baseline` | Conventional converter: same power stage and loops, no isolation |
| `*_rand00`–`*_rand09` | Random fault instants, 10 per fault type |
| `*_fuse`, `*_aval`, `*_relayonly_final` | Revision 2: input fuse, avalanche-energy integrator, relay-only isolation |
| `rev3_*` | Revision 3: saturation (`sat135`, `sat72`), transistor-level SSD (`ssdreal`), start-up (`su_orig`, `su_early`), double faults (`dbl`) |
| `*_noisy`, untagged, `*_c150u`, `*_relay5ms`, `*_linrepro` | Earlier development runs (relay-only or noise-free), kept for traceability |
